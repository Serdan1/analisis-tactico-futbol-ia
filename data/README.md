# data/

Aquí van los clips y los datasets. **Nada de esta carpeta se sube a GitHub** (salvo este archivo).

```
data/
├── clips/        # clips del proyecto: clip_01.mp4, clip_02.mp4...
├── anotaciones/  # frames con el jugador marcado a mano (validation y test)
└── soccernet/    # datos de SoccerNet (acceso con NDA: no compartir)
```

Para compartir clips entre el equipo, usad una carpeta compartida (Drive, OneDrive...) y descargadlos aquí.

Criterios para elegir clips: de 30 s a 2 min, plano general de televisión, 1080p si es posible, pocos cortes de cámara y un delantero bien visible.
